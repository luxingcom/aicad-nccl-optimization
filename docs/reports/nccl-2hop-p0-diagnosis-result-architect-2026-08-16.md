## 0. 裁定摘要（TL;DR）

1. **P0 分叉结论 = 前进 P1/P3/P5**，不触发提前终止。
   - **P0-1 64K δ_hw(p50)=1.30** = 边界值，**非 ≥1.7 终止线**；t_both 稳定（75.5/77.7µs）说明并发本身无崩溃，仅单边基线重尾造成 avg 摆动（0.748/1.331）。
   - **P0-2 B≥A（2-PG 反而慢 2.8-5x，含 ring 对照 5.05x）** → 走"单 PG 非主因"分支；交叉 P0-1 未达 ≥1.7 → **"伪影是 proxy 特有机制，移交 P5"**。
2. **S2 反转记录修正**：S2 的 1.84x@1K aligned<nobar 反转**未在 P0-2 复现**（A_vs_C@1K=1.06、4K=0.77、16K=0.61，方向正常）→ **S2 nobar avg 是重尾样本污染，非系统性仪器反转**。S2"结构信号不可判定"结论**维持**，但机制修正为：重尾（avg≈2×p50）+ 每-op 开销 + proxy 无法建模并发（B 模式 2.8-5x 证明），而非"恒定反转"。
3. **proxy 可建模性结论（重要）**：P0-2 B 模式证明 **torch 双 PG（per-edge）建模双口并发在小消息下开销巨大（2.8-5x），完全不可用** → 2-hop 的并发收益**只能由真实 kernel 裁决**（P5），S2/P0 的 torch 时序全部不具备 2-hop 收益判据资格。
4. **前进条件重申（硬门不变）**：P1 正确性/无死锁 → P3 真实 kernel capture（失败=NO-GO）→ P5 真实 kernel A/B @16K 主 +1K 参考，`ratio_real≤0.80`（失败=NO-GO）→ P2 per-edge channel 调度强制（因 64K δ_hw=1.30 边界 + 256K+ ≥1.7）。

## 1. P0-1 判读：V2b 64K δ_hw

| 指标 | 值 | 判读 |
|---|---|---|
| t_both | 75.5 / 77.7µs（两轮，稳定） | 并发路径稳定，无崩溃 |
| t_right / t_left | avg 摆动 52.9→103.9（重尾） | **单边基线重尾**，avg 不稳定 |
| **δ_hw(p50)** | **60.0 / max(46.3, 43.7) = 1.30** | **边界值**（≤1.3 档上限） |
| δ_hw(avg) | 0.748 / 1.331 | 受单边重尾污染，不可作判据 |
| ok | True | 数据正确 |

**裁定**：
- **64K 双口 = 边界/轻微争用，非串行化**（串行化应为 δ_hw≈2，即 t_both≈t_right+t_left≈90µs；实测 60µs，1.30x 单边）。
- **未达 ≥1.7 终止线** → 按 ≤1.3 边界处理，**不触发提前终止**。
- 含义：≤64K 延迟主导区双边步可行（无带宽翻倍需求，只需不崩溃）；256K+ 的 ≥1.7 串行化约束已确立 → **路由上限 ≤64K 维持**，P5 目标 16K 在安全区内。
- **建议（可选低成本补充）**：补一次 δ_hw@16K（P5 目标尺寸）直接确认，若顺手可用现有 bilateral_micro.py `--sizes 16384`；不阻塞前进。

## 2. P0-2 判读：三模式反转诊断（avg µs）

| 算法@size | A 单PG nobar | B 双PG(edge) nobar | C aligned | A_vs_C | B_vs_A | B_vs_C |
|---|---|---|---|---|---|---|
| 2hop@1K | 530.0 | 1499.7 | 498.9 | **1.06** | 2.83 | 3.01 |
| 2hop@4K | 467.1 | 1641.6 | 606.2 | **0.77** | 3.51 | 2.71 |
| 2hop@16K | 505.0 | 1556.9 | 824.2 | **0.61** | 3.08 | 1.89 |
| ring@1K | 345.7 | 1747.1 | 683.5 | — | **5.05** | 2.56 |

**判读**：
1. **S2 反转未复现（关键修正）**：A_vs_C（nobar/aligned）@1K=1.06（微反转，噪声内）、4K=0.77、16K=0.61（nobar 快于 aligned，物理正常方向）。→ **S2 的 1.84x@1K 反转是重尾样本，非系统性**。S2 nobar avg 的问题 = **重尾**（avg≈2×p50），而非恒定反转。
2. **B 模式（per-edge 双 PG）慢 2.8-5x，含 ring 对照 5.05x** → **双 PG 开销是 torch communicator 级伪影**（多 communicator + 多 batch + Python 开销在小消息下淹没一切），**不是硬件争用信号**。→ torch 双 PG 无法建模双口并发。
3. **B≥A → 走"单 PG 非主因"分支**；交叉 P0-1（δ_hw=1.30 非 ≥1.7）→ **"伪影是 proxy 特有机制，移交 P5"**。

## 3. 分叉裁定（对照终审裁定 §5.2 决策树）

| 分叉条件 | 实测 | 裁定 |
|---|---|---|
| P0-1 64K δ_hw | **1.30（边界）** | 未达 ≥1.7 终止线 → 不终止 |
| P0-2 B vs A | **B≥A（慢 2.8-5x）** | 单 PG 非主因 → 伪影为 proxy 特有 |
| S2 反转 | **未复现（1.06x@1K，4K/16K 方向正常）** | 反转=重尾样本，非系统性仪器失效 |
| 交叉结论 | 无"真实 ≤64K 双口背压"证据（δ_hw 1.30） | **前进 P1/P3/P5** |

**最终裁定：P0 分叉通过 → S3 前置原型门第一阶段启动（P1 → P3 → P5），P2 per-edge channel 调度强制。**

## 4. 对 S2 判读记录的两点修正（记入历史）

1. **"nobar 仪器对 2-hop 系统性失效（反转证明）"→ 修正为"nobar avg 重尾污染 + proxy 无法建模并发"**。反转是样本伪影，非仪器恒定失效。但 **ratio_m_nb(avg) 仍不可作 2-hop 主判据**（重尾使 avg 失真）；p50 版 S2 仍混合（1K=1.49/4K=1.22 不利、16K/64K=0.88/0.89 有利）→ **S2 结构信号"不可判定"结论维持**。
2. **"torch 双 PG 可建模双口并发"→ 证伪**：B 模式慢 2.8-5x → torch 级并发建模对小消息完全不可用 → **2-hop 收益只能由真实 kernel A/B（P5）裁决**。这进一步收窄 S2 能回答的问题集，加强"移交 P5"。
